Flujo de Validación OCR y Visión Computacional

Odoo 16 + FastAPI + PaddleOCR + YOLO

                %%{init: {'theme': 'base', 'themeVariables': { 'primaryColor': '#f3f4f6', 'lineColor': '#1e3a8a', 'fontFamily': 'sans-serif'}}}%%
                sequenceDiagram
                    autonumber
                    actor Usuario
                    participant Odoo as Odoo 16 (Gerente)
                    participant FastAPI as FastAPI (Coordinador)
                    participant PaddleOCR as PaddleOCR (IA Texto)
                    participant YOLO as YOLO (IA Visual)

                    rect rgb(240, 248, 255)
                    Note over Usuario, FastAPI: PASO 1: La Petición
                    Usuario->>Odoo: Sube PDF y hace clic en "Analizar"
                    Odoo->>FastAPI: Envía PDF por red interna (HTTP POST)
                    end

                    rect rgb(255, 248, 240)
                    Note over FastAPI, YOLO: PASO 2: El Análisis
                    FastAPI->>FastAPI: Convierte PDF a Imágenes
                    par Análisis de Texto
                        FastAPI->>PaddleOCR: Envía copia de imagen ("Búscame una fecha")
                        PaddleOCR-->>FastAPI: Extrae texto y retorna: "19-02-2026"
                    and Análisis Visual
                        FastAPI->>YOLO: Envía copia de imagen ("Búscame firma y huella")
                        YOLO-->>FastAPI: Detecta formas y retorna: Firma (Sí), Huella (No)
                    end
                    end

                    rect rgb(240, 255, 240)
                    Note over FastAPI, Odoo: PASO 3: El Veredicto
                    FastAPI->>FastAPI: Arma reporte JSON consolidado
                    FastAPI-->>Odoo: Responde {"firma": true, "huella": false, "fecha": "19-02-2026"}
                    end

                    rect rgb(253, 240, 255)
                    Note over Odoo, Usuario: PASO 4: El Resultado
                    Odoo->>Odoo: Procesa JSON y actualiza campos en BD
                    Odoo-->>Usuario: Marca checkboxes en pantalla (Tiempo: 2-5 seg)
                    end

Resumen de la arquitectura:

  • El procesamiento pesado ocurre fuera del ERP para evitar bloqueos.
  • PaddleOCR y YOLO trabajan en paralelo (al mismo tiempo) para reducir el tiempo de respuesta.
  • La comunicación se realiza mediante red interna.
